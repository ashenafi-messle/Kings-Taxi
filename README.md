# Kings Taxi — Transportation, Hotel & Tourism Platform

Kings Taxi is a premier multi-service mobility platform built for Ethiopia and regional tourism. It combines urban ride-hailing, verified hotel reservations, historical heritage tours, and full-contract multi-destination transportation into a single application.

## Repository Layout

```text
kings-taxi/
├── apps/
│   ├── passenger-mobile/   # Expo / React Native passenger mobile application
│   └── shared/             # Shared TypeScript types, utilities and constants
├── docs/                   # Architectural and development documentation
├── package.json            # Root workspace configuration
└── README.md
```
